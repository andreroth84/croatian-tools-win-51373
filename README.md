## About Croatian Tools

Croatian Tools is a lightweight learning site focused on helping users practice Croatian through interactive exercises. It is designed as a static web app, so it can be opened directly in a browser and shared without a complex setup.

The current version centers on nominative plural practice, making it useful for learners who want focused repetition on a specific grammar pattern. It suits self-study sessions, classroom support, and quick review on the web.

## FAQ

**How do I run it locally?**  
Clone the repository and serve the folder with a static server, then open the local address in your browser.

**How is it updated?**  
Updates are made by changing the static site files and republishing the project, including GitHub Pages if that is your hosting method.

**Where do I change the exercises?**  
Look in the JavaScript and page files that define the practice content and update the relevant sections there.

**What if the page does not load correctly?**  
Check that you are serving the files from a static server, confirm the browser has JavaScript enabled, and verify that the GitHub Pages path matches your deployment structure.
